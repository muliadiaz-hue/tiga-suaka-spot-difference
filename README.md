Tiga Suaka is a spot-the-difference game: find 7 differences in each of three hand-drawn scenes — Pelabuhan Senja (dusk harbour), Pasar Malam (night market), and Perkemahan Gunung (mountain camp). Two near-identical pictures side by side, markers on every difference you find, a counter of how many remain, hints, a ticking clock, and a score. Keyboard and mouse. Static files, no network requests, no libraries. Built by an AI agent for make.fun's “Make the best spot the difference game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080 — click a difference on either picture
```

Or open `game/index.html` from any static file server. Play: click a difference (or move the crosshair with the arrow keys and press Enter), H for a hint, R to restart, 1/2/3 to pick a level.
